# README - `./data/metadata/`

- `metadata/` contains metadata like data dictionaries or provenance information

## Data sources

### Australian Land Use and Management Classification Version 8 (October 2016)

A Vocabulary is available here: https://vocabs.ardc.edu.au/viewById/193, this vocabulary has persistent ids in `linked.data`, for example: https://linked.data.gov.au/def/alum/1.1.1

Spatial data layers *Land use of Australia 2010–11 to 2020–21*, version 7.1 are available from: https://doi.org/10.25814/n0z4-5y98

**Citation**: 

> ABARES 2026, Land use of Australia 2010–11 to 2020–21 version 7.1, Australian Bureau of Agricultural and Resource Economics and Sciences, Canberra, August, CC BY 4.0. DOI: 10.25814/n0z4-5y98

### Ecosystem extent from the NEAP project

This layers includes the extent of IUCN Global Ecosystem Typology ecosystem functional groups across the marine, freshwater and terrestrial realms in Australia for different time frames: pre-1750 and 2010-11 to 2023-24

We only download the crossreference ("cross-walks") for the ALUM layer.

**Citation**: 

> Macfarlane, Craig; Liu, Ning; Newnham, Glenn; Richards, Anna; & Tetreault Campbell, Sally (2025): Extent of IUCN Global Ecosystem Typology ecosystem functional groups across the marine, freshwater and terrestrial realms in Australia: pre-1750 and 2010-11 to 2023-24. v6. CSIRO. Data Collection. https://doi.org/10.25919/qy5a-zj69
